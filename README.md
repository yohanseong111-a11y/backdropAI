# BackdropAI

Bulk background removal and product-photo editor for desktop and mobile browsers.

This build adds a minimal hero description, smoother worker-backed scan animation, real cutout reveal behind the scanner, conservative edge cleanup, safer product-preserving retries, current-background preview, selectable per-photo positioning and filters, assisted tap-based erase/restore, manual mouse/touch cutout editing, high-quality subject re-check, and ZIP export.

The actual AI inference time still depends on the browser/device/GPU. The final scanner reveal uses the real processed cutout rather than a fake mask.
